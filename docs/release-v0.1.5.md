# 诺亚舟NPE v0.1.5（预发布）

修复 H1 部分左右实体键无效的问题，并支持按游戏自定义底部触摸按键。

- 同时接受左右方向键的两组固件矩阵编号，并统一长按和松开状态；不再因共享扫描码遗漏方向事件。
- 暂停菜单增加“触摸按键设置”。前七个按钮可改为字母、Shift 大写、数字、方向、确认、空格、F4、删除、翻页键或符号；第八个固定为“菜单”。
- 按游戏完整路径保存 `.npe.h1keys` 配置，重新打开自动恢复；支持保存、恢复默认及取消未保存修改。
- 配置文件可在电脑上用 UTF-8 编辑，支持短中文名称。使用安装包自带原生字库绘制自定义名称。
- 触摸按键配对发送按下与松开；字母直接送入引擎，不被 H1 的 Z/X/P 快捷键替换。
- CI 新增实际 MIPS 输入回归：两组方向编号、长按、松开、配置隔离、编辑与重载、无效配置、Shift 和固定菜单入口。

保留 v0.1.4 后台合成、仅提交变化像素的闪底色修复。真机闪屏和本版左右键修复仍待用户复验。
验证范围及构建身份见 `docs/verification.md`、`docs/evidence/release-v0.1.5.json`。
模拟服务表测试与完整固件 QEMU 验证分别记录，不代替真机测试。

下载 `BBKH1-NPE-v0.1.5-install.zip`，将 `应用`、`NPE` 合并到 H1 的 A 盘。
已有程序和字体时可只替换 `H1NPE.bda`；自定义步骤见安装包的 `NPE/touch-keys.md`。
游戏和存档无需迁移，游戏与固件不打包。提供完整固定依赖源码和 SHA256 清单。
