# 诺亚舟NPE v0.1.0（预发布）

首个步步高 H1 / Y100 V1.41 原生 BDA 移植版本，H1 菜单名称为“诺亚舟NPE”。

- 原始 240×120 游戏画面支持 1x / 2x 显示，带触摸操作栏和暂停设置。
- 接入 H1 实体按键、触摸、32000 Hz 原生 PCM、GBK 文件路径和三个手动存档槽。
- 未选择 NPE 时，关闭文件选择器或按 Escape 可恢复桌面。
- 应用图标采用诺亚舟学习机元素和 H1 高光圆角风格。

下载 `BBKH1-NPE-v0.1.0-install.zip`，把 `应用`、`NPE` 两个目录合并到 H1 的 A 盘。
保留 `NPE/assets/` 内的两个字体文件，自己的 `.npe` 游戏放入 `A:\NPE\`。
也提供独立 `H1NPE.bda` 和含固定 SDK/NPE 依赖的完整源码 ZIP。
文件完整性使用同次 CI 生成的 `SHA256SUMS.txt` 核对。

SDK 固定提交：`067fe072477861dfc8949d7b1a55279fb92d2548`。
NPE 固定提交：`942b645ba26693db43c32375f28d53d32d1da099`。

`61663b93ff028da42213c3b137c891c4c6577efb3e5cabbbe48b7c4a95e7ba63`。

已有真实 MIPS 自动测试和完整 H1 V1.41 固件模拟器的开场/地图、暂停、显示、第二槽存取档、
文件列表取消及退出验证。当前 BDA 的可执行载荷与完整固件游戏流程测试版本逐字节一致；
名称和图标更新的构建身份分别保留于证据记录。CI 另外执行取消和坏资源 MIPS 测试。
