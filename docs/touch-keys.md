# 按游戏自定义底部触摸按键

进入暂停菜单，选择“触摸按键设置”。点击要改的按钮，再选功能；可用上下左右和确认键操作。
功能列表支持字母、Shift 大写、数字、方向、确认、空格、F4、删除、上页、下页和加号。
“空”禁用该按钮。“上一页/下一页”或实体翻页键切换功能列表页。

底栏前七个按钮可修改，第八个固定为“菜单”，用于暂停和再次设置。
“保存返回”写入当前游戏的配置并立即生效；“恢复默认”需要再保存才会生效。
返回键退出设置时取消尚未保存的修改；在功能列表中按返回，只返回按钮选择。

每个游戏使用同目录、完整文件名加 `.h1keys` 的配置文件，例如：

```text
A:\NPE\天降风云.npe
A:\NPE\天降风云.npe.h1keys
```

未配置的游戏使用原来的“左、右、上、下、确认、对话、返回”。
切换游戏或退出后重开会重新加载该游戏的配置；配置文件不改变游戏和存档。

## 在电脑上编辑

用 UTF-8（可带 BOM）保存，接受 LF 和 CRLF 换行。按钮编号从左到右为 1～7。
格式是 `编号=按键|显示名称`，名称可省略。例子仅演示绑定，实际功能由游戏决定：

```ini
# H1NPE touch keys v1; UTF-8
1=LEFT|左
2=RIGHT|右
3=a|攻击
4=b|魔法
5=ENTER|确认
6=F4|返回
7=p|特殊
```

按键名区分大小写：`a`～`z` 发送小写字母，`A`～`Z` 发送字母加 Shift；
`0`～`9`、`=`、`+` 为数字和符号。
其他按键名为 `LEFT`、`RIGHT`、`UP`、`DOWN`、`ENTER`、`SPACE`、`F4`、
`BACKSPACE`、`PAGEUP`、`PAGEDOWN`、`NONE`。
字母直接送给 NPE；底栏绑定 `p` 不会打开 H1 暂停菜单，绑定 `z`/`x` 也不会被 H1 快捷键替换。
引擎本身对 I/J/K/L/M 等键的解释仍按游戏模式处理；大写与加号主要用于问答模式。

自定义名称最多占 48 像素，约三个中文字符或六个 ASCII 字符；中文须能编码为 GBK。
使用安装包内的 `gbk16-native.bin` 绘制。无效/过长名称回退到按键默认名称。
配置最多 1 KiB；未知按键、无效编号或无效行会忽略，其他按钮保留默认。
文件过大或含零字节时整份配置回退到默认。第八个“菜单”不能被配置覆盖。
保存失败时留在设置界面，当前生效布局不变；检查空间或路径后可以重试。
