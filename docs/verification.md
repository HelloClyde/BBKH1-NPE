# H1 NPE v0.1 移植验证

日期：2026-10-11。正式 BDA 与安装 ZIP 由 `tools/build.py` 生成。
准确的源码版本、编译器、文件大小与 SHA-256 见 `dist/H1NPE.build.json`。

## 构建与内存

- MIPS32 little-endian、o32、soft-float、freestanding，入口 `0x83c00020`。
- GNU GCC 15.2.0；九个 NPE 核心/前端源文件和 H1 适配层交叉编译、链接通过。
- H1 SDK BDA 头、菜单资源与镜像尺寸校验通过；重复构建 BDA 摘要一致。
- 上游依赖保持干净并锁定提交；构建目录替换手柄适配器，H1 实体键产生原前端键盘事件。
- 应用 BSS 包含独立 1 MiB 栈；链接器检查整个静态镜像和栈不超出 H1 的 4 MiB 加载窗口。
  前端启动栈帧约 277 KiB，绘制帧另需约 115 KiB，不能沿用 GBA 项目的 128 KiB 栈。
- SDK 临时诊断菜单图标用于此初版。

## 完整 H1 固件

使用本机 H1 V1.41 `project.bin`、QEMU `bbkh1`、64 MiB、独立可写 NAND。
未修改原始 `E:\bbk\H1` dump；没有向固件注入 NPE 宿主服务。
沿用模拟器的桌面壁纸回退补丁，测试应用放在私有镜像的原生游戏菜单槽。
固件镜像、游戏文件和运行存档留在忽略的 `build/firmware/` 中。

- 原生文件选择器从 `A:\NPE\` 显示 `.npe`，正常载入开场、标题和地图。
- 原画面 2x 放大到 480×240，底部 32 像素触摸栏；触摸切换为居中 240×120。
- 实体返回键打开游戏菜单；保存到第二槽后移动，再从第二槽读回。
  只读 NAND 提取保存文件：2,366 字节、`NPESAV22`、地图 1、坐标 43,2。
- 底栏 MENU 与 P 都能暂停；已确认触摸继续和显示切换。
- 原生 PCM 输出为 32000 Hz；结束日志记录 2,107,416 个非零样本、0 丢弃、0 接口失败。
  本次长流程有 1 次环形缓冲欠载，不能据此声称声音始终连续或真机流畅。
- Escape 正常返回桌面，日志以 `APP_END result=0` 结束。
- 选择器取消会进入游戏显示模式，移植层配对调用窗口开/关以恢复桌面。
  此取消分支和错误分支目前由 MIPS 服务表测试覆盖，完整固件未重复验收。

报告：`build/firmware/native-verification.json`；复核命令：

```powershell
python tools/verify_firmware_evidence.py
```
