# 诺亚舟NPE v0.1.4（预发布）

针对用户真机反馈的“游戏画面反复闪黑/闪底色”，修复每帧在 LCD 显示缓冲上先清屏再绘制的过程。

- 先在后台合成完整游戏画面、触摸栏或暂停菜单，再把变化像素写入 LCD 缓冲。
- 相同游戏画面和暂停菜单不再重复写屏；2倍显示下，单个源像素变化只写四个显示像素。
- 切换1倍/2倍、固件显示缓冲改变或重新打开窗口时，正确恢复完整画面与边框。
- 新增真实 MIPS 写屏回归：检查每次 LCD 写入，旧版清屏行为会失败；该测试不需要游戏或固件，已接入 CI。
- 增加1,044,480字节静态显示缓存，保留1MiB应用栈，并通过4MiB加载窗口限制检查。

正式 BDA 完成 MIPS 显示、存档、触摸、静音和退出测试，以及完整 H1 V1.41 固件模拟器回归。
验证范围见 `docs/verification.md` 和 `docs/evidence/release-v0.1.4.json`。
此次修复仍待用户真机复测；模拟器和 MIPS 写屏检查不能证明真机闪屏已经消失。

下载 `BBKH1-NPE-v0.1.4-install.zip`，将 `应用`、`NPE` 合并到 H1 的 A 盘。
已安装旧版和字体时，可只替换 `H1NPE.bda`。游戏与存档文件无需迁移。
提供完整源码 ZIP、构建/验证记录和 SHA256 清单；游戏与固件不打包。
NPE 引擎保持上游 v0.1.3 / `567ae64`，H1 SDK、菜单文字、图标和名称保持已有版本。
