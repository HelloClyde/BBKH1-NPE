# 诺亚舟NPE v0.1.7（预发布）

暂停菜单新增音量控制，范围 0%～100%，每次调整 10%。
选中“音量”时用左右键调节，确认进入触摸调节页；触摸 - / + 也可加减。
返回键、确认键或触摸“返回菜单”返回暂停菜单。

保留独立声音开关，关闭再开启恢复所选音量。100% 保持原始 PCM，0% 静音仍推进音频回调。
只调整本程序音频，不修改 H1 系统音量；本次运行换游戏时保留，重新启动默认 100%。
保留作者 HelloClyde 的关于页、左右键兼容、按游戏触摸配置和闪底色修复。
音量与 PCM 输出已通过实际 MIPS 回归，界面和触摸通过完整 H1 V1.41 固件 QEMU 验证。
验证身份见 `docs/evidence/release-v0.1.7.json`；未做真机复验。

下载 `BBKH1-NPE-v0.1.7-install.zip` 安装；已有程序和字体时只需替换 `H1NPE.bda`。
游戏、存档及触摸键配置无需迁移，发布包不包含游戏或固件。
