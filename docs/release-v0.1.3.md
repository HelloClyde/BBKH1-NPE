# 诺亚舟NPE v0.1.3（预发布）

H1 同步上游 NPE 引擎 v0.1.3，修复普通攻击姿势和伤害数字闪过过快的问题。

- NPE 子模块固定为 `567ae64c1ba67c8a55d0c4fbdf874f9ac58471cf`。
- 上游将攻击姿势的等待由 10ms 修正为 200ms，通用伤害数字等待修正为 100/600/600ms，中毒数字每段 600ms。
- 仅调整显示等待；上游没有修改战斗计算、存档格式或剧情出口条件。
- 保留中文菜单、触摸操作栏、诺亚舟学习机图标和“诺亚舟NPE”名称；H1 SDK 固定版本不变。
- README 更新依赖版本及本次正式 BDA 的完整固件模拟器截图，历史证据保持原构建身份。

正式 BDA 完成交叉编译、MIPS 加载/菜单/存储/退出回归及完整 H1 V1.41 固件运行验证。
同一正式 BDA 从独立测试存档进入普通战斗，采集攻击姿势、伤害数字、敌方回应和回合结束帧，
确认显示停留清晰可见并正常退出；采样时间为模拟器主机时间，不代表真机速度。
验证范围与摘要见 `docs/verification.md`、`docs/evidence/release-v0.1.3.json`。

下载 `BBKH1-NPE-v0.1.3-install.zip`，将 `应用`、`NPE` 合并到 H1 的 A 盘。
安装文件名为 `H1NPE.bda`，保留两个 GBK 字体，游戏文件自行提供。
发布包提供完整源码 ZIP、构建/验证记录和 SHA256 清单。
